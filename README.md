## Quick checklist

- [ ] Choose one high-intent trigger
- [ ] Confirm event data quality
- [ ] Write suppression rules and frequency caps
- [ ] Create a holdout group
- [ ] Define the success metric

## Terms

- **Trigger:** a user action or missing action that starts a journey.
- **Suppression rule:** a condition that stops a message from being sent.
- **Frequency cap:** the maximum number of messages one person receives in a set period.
- **Holdout group:** a set of users who receive no message, used to measure true lift.
- **Orchestration:** deciding the next best message, timing and channel from live data.
